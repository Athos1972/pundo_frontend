# Σύνδεση Pundo με τον AI βοηθό σου

![Laptop με ανοιχτό AI βοηθό δίπλα σε φραπέ σε ηλιόλουστη βεράντα στη Λάρνακα](/images/guides/pundo-mcp-server.png)

Ρωτάς τον AI βοηθό σου: «Πού βρίσκω ρωσικό μέλι στη Λάρνακα;» — και αντί για εικασίες, παίρνεις πραγματικά καταστήματα και τιμές από το Pundo. Δεν είναι σχέδιο για το μέλλον. Λειτουργεί τώρα.

## Τι είναι ο Pundo MCP Server;

Το MCP σημαίνει **Model Context Protocol** — ένα ανοιχτό πρότυπο που επιτρέπει στους AI agents να αντλούν δεδομένα από εξωτερικές πηγές. Το Pundo διαθέτει δικό του MCP server στη διεύθυνση `mcp.pundo.cy`.

Απλά: ο AI βοηθός σου μπορεί να ψάχνει στο Pundo απευθείας, χωρίς να χρειάζεται να ανοίξεις την εφαρμογή.

<InfoBox type="info">
  Ο MCP server παρέχει πρόσβαση μόνο για ανάγνωση — αναζήτηση προϊόντων, καταστημάτων και κατηγοριών. Δεν υποστηρίζονται παραγγελίες ή αλλαγές δεδομένων.
</InfoBox>

## Σύνδεση σε τρία βήματα

Δεν χρειάζεται να αντιγράψεις κανένα κλειδί, ούτε τεχνική ρύθμιση. Χρειάζεσαι μόνο τον λογαριασμό σου στο Pundo.

Μετά τη σύνδεση, η εξουσιοδότηση αποθηκεύεται. Δεν θα χρειαστεί ξανά κωδικός.

<InfoBox type="tip">
  Μπορείς να αποσυνδεθείς ανά πάσα στιγμή από το **Ο λογαριασμός μου → AI Agents** — χρήσιμο αν αλλάξεις συσκευή.
</InfoBox>

## Τι μπορείς να ρωτάς;

Μόλις συνδεθεί το Pundo, ο agent σου μπορεί να απαντά σε ερωτήσεις όπως:

- «Ποια καταστήματα στη Λάρνακα πουλάνε βιολογικό ελαιόλαδο;»
- «Σύγκρινε τιμές χαλλουμιού σε διαφορετικά καταστήματα»
- «Δείξε μου τροφές για κατοικίδια κοντά μου»
- «Υπάρχει ρωσικό παντοπωλείο στη Λεμεσό;»

Ο agent ψάχνει στο Pundo σε πραγματικό χρόνο και σου επιστρέφει όνομα καταστήματος, διεύθυνση και τιμή — κατευθείαν στη συνομιλία.

## Όρια χρήσης

Ο Pundo MCP server είναι δωρεάν. Ισχύει ένα όριο ευλογοφανούς χρήσης — **500 αιτήματα την ημέρα** ανά λογαριασμό. Για κανονική χρήση είναι παραπάνω από αρκετό.

<InfoBox type="info">
  Το όριο αφορά τον λογαριασμό Pundo, όχι τη συσκευή. Μπορείς να χρησιμοποιείς τον ίδιο λογαριασμό σε πολλές συσκευές.
</InfoBox>

## Διαχείριση συνδέσεων

Στο **Ο λογαριασμός μου → AI Agents** βλέπεις ποιοι clients είναι συνδεδεμένοι και πότε ήταν τελευταία ενεργοί. Μπορείς να αποσυνδέσεις οποιονδήποτε με ένα κλικ.
