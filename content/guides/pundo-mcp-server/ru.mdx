# Подключить Pundo к ИИ-ассистенту

Спрашиваешь ИИ-ассистента: «Где в Ларнаке найти русский мёд?» — и вместо предположений получаешь реальные магазины и цены из Pundo. Это не планы на будущее. Это работает уже сейчас.

## Что такое Pundo MCP-сервер?

MCP расшифровывается как **Model Context Protocol** — открытый стандарт, позволяющий ИИ-агентам обращаться к внешним источникам данных. Pundo запускает собственный MCP-сервер по адресу `mcp.pundo.cy`.

Проще говоря: твой ИИ-ассистент может искать в Pundo напрямую, без необходимости открывать приложение.

<InfoBox type="info">
  MCP-сервер предоставляет доступ только для чтения — поиск товаров, магазинов и категорий. Заказы и изменения данных недоступны.
</InfoBox>

## Подключение за три шага

Никаких API-ключей, никаких технических настроек. Нужен только аккаунт Pundo.

<StepList steps={[
  "Открой своего ИИ-агента (например, Claude Desktop) и перейди в Настройки → MCP → Добавить сервер",
  "Введи URL: https://mcp.pundo.cy — это всё",
  "При первом подключении откроется окно браузера. Войди в свой аккаунт Pundo и нажми «Разрешить»"
]} />

После авторизации соединение сохраняется. Пароль больше запрашиваться не будет.

<InfoBox type="tip">
  Отключить соединение можно в любой момент в разделе **Мой аккаунт → ИИ-агенты** — например, перед передачей устройства другому человеку.
</InfoBox>

## Что можно спрашивать?

После подключения Pundo твой агент справится с такими запросами:

- «Какие магазины в Ларнаке продают органическое оливковое масло?»
- «Сравни цены на халлуми в разных магазинах»
- «Покажи корм для животных рядом со мной»
- «Есть ли русский продуктовый магазин в Лимассоле?»

Агент ищет в Pundo в режиме реального времени и возвращает название магазина, адрес и цену — прямо в чате.

## Лимиты использования

Pundo MCP-сервер бесплатный. Действует лимит честного использования — **500 запросов в день** на аккаунт. Для обычного использования этого более чем достаточно.

<InfoBox type="info">
  Лимит действует на аккаунт Pundo, а не на устройство. Один аккаунт можно использовать на нескольких устройствах.
</InfoBox>

## Управление подключениями

В разделе **Мой аккаунт → ИИ-агенты** отображается список подключённых клиентов и время последней активности. Любое соединение можно отключить одним кликом.
