Save does not start the job. Products from a shop's catalog import are queued automatically. Products created in the admin wait until the team starts the next translation run.

What you can steer, and what not

Products: there is no translation screen in the admin.

You control

  • The source text: name and description
  • Plain wording: brand, product, size
  • Category names, one per language

You do not control

  • The wording of a single language of a product
  • When the translation job runs
  • A re-translation of an existing language
A translation looks wrong? Note the product and tell the team lead. Retyping the name does not fix it.

Other languages stay, but they are not updated. Changed the English text? Tell the team lead, so the other languages can be checked. The translation job never overwrites an existing language version. Translation wrong? Tell the team: they decide about a re-translation.
